OpenYard

Petit cloud open source : un projet, des containers sur Kubernetes, des VM Linux. Tout se crée dans la console.

Entrer dans la console Code source
exemple · POST /projects 
$ curl -s localhost:8000/projects \
  -H 'content-type: application/json' \
  -d '{"name":"acme","pods_quota":10}'

# namespace oy-acme + clé oy_…

$ curl -s localhost:8000/workloads \
  -H "X-API-Key: oy_…" \
  -d '{"name":"web","image":"nginxinc/nginx-unprivileged:1.27-alpine","apply":true}'

Trois briques

Pas un clone AWS. Juste ce qu’il faut pour montrer un control plane.

Projets

Tenant, namespace, quotas, clé API.

Workloads

Image Docker → Deployment, Service, Ingress.

VM Linux

Ubuntu en sim ou via Multipass.

Ordre d’usage

Même flux dans la console et via l’API.

  1. Créer un projet

    Tu reçois une clé API et un namespace oy-….

  2. Déployer un workload

    Image, port, réplicas. Apply crée les pods et l’Ingress.

  3. Lancer une VM si besoin

    Ubuntu 22.04 / 24.04 — start, stop, delete.

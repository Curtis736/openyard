De l’image au pod en 4 étapes

La console fait la même chose que l’API — sans curl.

  1. Créer un workload

    Nom, image Docker, port, réplicas. Optionnellement expose un Service.

  2. Inspecter le manifest

    YAML Deployment + Service généré côté control plane.

  3. Apply sur le cluster

    kubectl-like via le client Kubernetes Python (in-cluster ou kubeconfig).

  4. Suivre le statut

    Ready / deploying / registered — pods listés depuis l’API cluster.
